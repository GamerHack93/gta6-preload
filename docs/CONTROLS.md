# Dev Kit Controls (keyboard / mouse)

| Action | Key |
|---|---|
| Move | W A S D |
| Sprint | Shift |
| Jump / climb | Space |
| Enter vehicle | F |
| Character swap | Alt + Tab-wheel |
| Phone | ↑ |
| Debug console | F8 |
| Free camera | F9 |
| Screenshot (no HUD) | F12 |
| Toggle HUD | Ctrl + H |
